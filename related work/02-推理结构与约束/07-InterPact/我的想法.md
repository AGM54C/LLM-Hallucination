# Is This Evidence Decision-Critical? Learning to Verify Rule-Governed Decisions

[原文入口](https://arxiv.org/abs/2609.39608v1) · [本地 PDF](原文.pdf) · 26 页

**一句话：**识别证据中的条件，与让规则决策依赖该条件，并不相同。

**怎么做：**用规则与证据构造决策关键性任务，并以匹配的训练对照检验条件验证和决策之间的联系。

**局限：**规则化任务的受控收益不能直接外推为科学因果或实验风险判定。

**课题对应：**训练与行为对照参考｜3.1.3 条件是否真正影响判断；未直接覆盖科学因果或实验风险。

**我的想法：**为同一条件构造改变结论和不应改变结论的配对样本，检验条件识别能否转成正确决策。若讨论选样或训练收益，应控制难度、样本覆盖和预算；这篇不能替已归档表格方案提供机制结论。

原文定位：方法、决策关键性定义与训练消融。
