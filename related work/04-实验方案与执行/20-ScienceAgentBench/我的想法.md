# ScienceAgentBench: Toward Rigorous Assessment of Language Agents for Data-Driven Scientific Discovery

[原文入口](https://arxiv.org/abs/2410.05080v3) · [本地 PDF](原文.pdf) · 60 页

**一句话：**科研代码能运行与其结果满足科学任务要求，需要分别判断。

**怎么做：**从真实工作流整理 102 个 Python 任务，分别评价有效执行与任务成功，并比较直接生成、自调试等方法。

**局限：**任务受公开材料与评价标准限制；主表含三次择优，不能当单次成功率，部分图像评价仍靠模型。

**我的想法：**候选 03 若先用计算实验，应同时保留执行与语义检查，报告总重试成本；不能据此宣称已覆盖湿实验可实施性。

原文定位：任务构造、Table 3、Appendices E、J。
