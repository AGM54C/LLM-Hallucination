# SciMON: Scientific Inspiration Machines Optimized for Novelty

[原文入口](https://arxiv.org/abs/2305.14259v7) · [本地 PDF](原文.pdf) · 21 页

**一句话：**检索灵感、生成科研想法和新颖性修订已有参数训练方案。

**怎么做：**结合相近工作、知识图谱和引用检索，训练生成器，并迭代降低与既有想法的相似度。

**局限：**检索空间有限；低文本相似度不等于科学新颖性。部分检索还使用原论文的引用集合。

**我的想法：**不能再说已有科学构思方法全靠提示。若继续做学习方法，需要明确改善哪类证据错误，并用可核验终点替代仅凭语言模型评价想法。

原文定位：方法章节；Appendix B；Tables 3–4。阅读记录核于 2026-10-08，本文为精简整理，未独立复现实验。
