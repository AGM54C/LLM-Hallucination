# CausalFlow: Causal Attribution and Counterfactual Repair for LLM Agent Failures

[原文入口](https://arxiv.org/abs/2605.25338v1) · [本地 PDF](原文.pdf) · 30 页

**一句话：**替换局部步骤、重跑下游并选择较小修复，已有反事实诊断流程。

**怎么做：**对失败轨迹提出候选替换，保留前缀并检查结果，形成错误与修复步骤对。

**局限：**部分任务的核验依赖模型预测，提示使用正确答案，且若干计数不自洽；成功替换不等于唯一根因。

**课题对应：**修复方法参考｜4.1.3 风险位置诊断、局部替换与有效性核验。

**我的想法：**让诊断器在看不到正确答案和错误位置时提出修改，重跑受影响步骤并独立验收。与同预算重采样比较净修复收益，才能区分局部诊断的作用与多试一次的收益。

原文定位：§§3–4、Tables 1–4、10–11、Appendix C.6。
