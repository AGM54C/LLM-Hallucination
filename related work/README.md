# 30 篇重点文献

围绕课题的结构化表示、科学机理约束、因果边界和实验方案修复选取。化学表格实验只是一个已归档候选，不再决定整个文献清单。

先读 **SciFact、VeryTrace、SCHEMA、BioPlanner、LAB-Bench、SciRigor**，分别了解证据核验、约束检查、轨迹诊断、协议规划、协议修复评价和科学支持链。各主题中的其他文章用于检查近邻与评价边界。

每篇目录仅有原文 PDF 和中文《我的想法》。保留直接近邻、方法基础与关键评测，不代表完整综述，也不能据此保证没有相似工作。选择一项 IDEA 后仍需针对具体问题查重。
