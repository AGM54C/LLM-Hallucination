# Stored Is Not Supported: Typed Provenance and Assertion Guardrails for Persistent AI Agents

**一句话：**信息被存进记忆，并不意味着它仍然支持当前主张。

**怎么做：**以来源角色、有效范围、依赖撤销和断言守卫约束持久化代理。

**局限：**规范、原型和支持关系不能替代世界真值，也不等于已验证的端到端可靠系统。

**我的想法：**证据发生撤回时，应沿依赖关系更新结论，并保留不受影响的结论。这个原则已有先例，价值需要用具体错误与对照说明。
