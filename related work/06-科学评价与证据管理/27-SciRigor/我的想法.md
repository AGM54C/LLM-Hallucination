# SCIRIGOR: Evaluating Open-Ended Scientific Analysis Beyond Final Scores

[原文入口](https://arxiv.org/abs/2609.06192v1) · [本地 PDF](原文.pdf) · 21 页

**一句话：**科学分析的评价需要追踪数据、变换、结果与结论之间的支持关系。

**怎么做：**审查同次运行的分析产物与依赖链，区分局部自洽和整体目标正确性。

**局限：**外部产物的完整证据链不等于模型隐藏状态的因果机制。

**我的想法：**实验结果目录应让每个数字都能回到原始记录和评分规则。未来评价不仅看最终答案，也检查依据是否来自正确条件和正确运行。

原文定位：评价框架、证据链及实验章节。阅读记录核于 2026-10-08，本文为精简整理，未独立复现实验。
