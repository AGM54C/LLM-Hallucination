# Does Reinforcement Learning Really Incentivize Reasoning Capacity in LLMs Beyond the Base Model?

[原文入口](https://arxiv.org/abs/2504.13837v5) · [本地 PDF](原文.pdf) · 31 页

**一句话：**训练后单次表现改善与可解问题集合扩大是不同的能力主张。

**怎么做：**比较不同模型和算法的 pass@k、可解集合及推理路径似然。

**局限：**结论取决于采样预算、任务和基础模型；不能据此断言强化学习永远不能产生新能力。

**我的想法：**当前单种子 SFT 提分只是一项行为结果。若主张训练带来新能力，应明确评测预算，并检查原模型是否本就能通过其他呈现完成任务。
