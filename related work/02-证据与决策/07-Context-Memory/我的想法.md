# How Do Language Models Choose Between Context and Memory?

[原文入口](https://arxiv.org/abs/2609.00753v2) · [本地 PDF](原文.pdf) · 17 页

**一句话：**模型在上下文与参数记忆冲突时，信息可读出不保证被用于回答。

**怎么做：**通过受控上下文冲突、内部读出与激活干预研究证据和记忆的竞争。

**局限：**特定任务上的读出与干预结果不能直接解释所有数值比较错误。

**我的想法：**我们的独立读数请求只能说明行为差异。要声称模型原本知道却没使用，必须回到同一自然失败轨迹，并区分检索、比较和答案映射。
