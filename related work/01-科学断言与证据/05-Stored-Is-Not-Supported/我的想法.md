# Stored Is Not Supported: Typed Provenance and Assertion Guardrails for Persistent AI Agents

[原文入口](https://arxiv.org/abs/2609.02127v1) · [本地 PDF](原文.pdf) · 17 页

**一句话：**信息被保存或附上来源，不自动获得支持某项断言的资格。

**怎么做：**区分来源角色、作用范围、有效期和依赖，用支持状态及撤销规则控制可输出的断言。

**局限：**核心是规范与小规模确定性一致性案例，没有真实智能体端到端优势验证；成立依赖抽取与来源正确。

**课题对应：**表示与规则参考｜3.1.2 事实和边界约束、3.1.3 支持关系与失效传播。

**我的想法：**可借用来源角色、作用范围和有效期来标记证据资格，测试证据撤销后哪些结论仍有独立支持。需要另验证自然语言抽取和真实任务收益，不能把规范设计的小例子当完整系统效果。
