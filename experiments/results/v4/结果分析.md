# V4 · 输出顺序与别名映射

**结论：正确读值后的错误选择仍然存在，并对呈现敏感；一个简单的末两项或 C/D 规则不能解释全部错误。**

## 为什么做、验证什么

V3 的部分错误符合“只比较最后两项”，但输出恒为 ABCD：最后两项、字母 C/D、当时对应的化学选项是重合的。本轮把这些因素拆开，检查错误更随**输出位置、字母标签还是化学身份**变化。该解释来自 V3 的事后错误分析，不是已观察到的内部算法。

## 方法与对照为何这样设置

| 因素或检查 | 实际方法 | 设计依据 |
|---|---|---|
| 输出顺序 | 联合输出 `values` 后再给 `choice`；四值按 ABCD 或 CDAB 输出 | 交换最后两项所占的字母，使“最近两项”与“固定 C/D”产生不同预测。 |
| 别名映射 | 四种循环轮换，全文一致地重命名化学选项 | 每个化学选项都经过 A/B/C/D，分开字母偏好与固定化学身份；没有穷举全部 24 种排列。 |
| 表内记录顺序 | 固定为全表打乱 seed 0，产率和化学身份不变 | 避免再把行序变化混入上述两个因素。 |
| 最高与最低 | 对同一表格和目标分别求最大、最小 | 检查是否遵守比较方向，而非总偏向大数或某个标签。 |
| 全量评价 | 对全部 330 题执行八种组合，不只重测 V3 错题；条件请求顺序打乱 | 同时观察修复和新增错误，避免只在挑出的错题上得出改善结论。 |
| 干净读值筛选 | 四值在 0.0005 个百分点容差内，且读数最优集合与真值完全一致 | 排除抄值或舍入改变排名；格式失败另报，并保留在总体分母。 |
| 同样读值→程序 | 对每次实际输出的四个数字确定性比较 | 保持提取质量相同，估计最后选择步骤还能避免多少损失。 |

候选规则分别只比较：实际输出的最后两项、字母 C/D、原映射下对应 C/D 的两个化学选项。比较这些规则与错误选择的吻合情况，能筛查简单行为解释；多个规则给出同一答案时，吻合本身没有区分力，也不能据此判断模型内部确实执行了该规则。

**方法性质：这是输出顺序 × 别名映射的因子对照。** 它改变可见输入和输出要求，没有读取隐藏状态、干预激活或提出新的训练方法。

## 结果与边界

330 个任务 × 4 种循环别名映射 × 2 种输出顺序（ABCD/CDAB），每模型 2,640 次生成，两模型共 5,280 次。表中记录保持同一打乱顺序。

| 指标 | 原始模型 | 普通 SFT |
|---|---:|---:|
| 决策准确率 | 93.33% | 94.73% |
| 同样读值→程序比较准确率 | 97.73% | 98.45% |
| 数值正确且最优集合不变的呈现 | 2,471 | 2,507 |
| 其中选择错误 | 115 | 100 |
| 这些错误占全部呈现 | 4.36% | 3.79% |
| 四值无效输出 | 4 | 4 |

所有决策格式合法、输出顺序合规；4 次数值无效保留在工作流分母中。正确读值后的错误贡献了总决策损失的 69.4% / 78.8%。

八种呈现中，没有一个任务在全部八种条件下都错误。末两项、固定标签和原化学身份的候选规则各能解释部分错误，但都不完整；这也不能排除它们之间的交互。

下一轮 V5 固定每条响应实际输出的数字，不纠正读错的数值，只比较新请求里是否保留原表。V4 本身没有内部干预或新训练。
