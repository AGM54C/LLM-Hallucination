# V2 · 顺序与独立读出

**结论：保持同目标的四条记录相邻时较稳，完全打散会明显降低直接选择准确率。** 独立读值后用程序比较是强基线。

验证集最大值任务：

| 呈现 | 原始模型 | 普通 SFT |
|---|---:|---:|
| 原序 | 84.85% | 96.97% |
| 全表逆序 | 83.64% | 94.55% |
| 底物块换序，三种排列平均 | 85.45% | 95.96% |
| 块内换序，三种排列平均 | 82.42% | 94.34% |
| 全表打乱，三种排列平均 | 64.24% | 74.55% |

原序与逆序各 165 次，三种排列共 495 次，仍是同一批任务的重复测量。全打乱同时改变位置、跨度与邻近关系，尚不能识别唯一内部机制。

全打乱 seed 0 下，模型独立读出数值后交给程序比较，最大值准确率达到原始模型 98.79%、普通 SFT 100%。这些读出和原直接决策来自不同请求，不能据此断言原轨迹“已经知道但没有使用”。

V2 还补齐基座测试最大值：原序 83.89%、全打乱 61.67%。最小值目标与最大值不同，完整结果见 [summary.json](summary.json)。
