# V5 · 同样的数值，有无原表

**结论：去掉表格、另问一次，没有改善整体表现。V5 不支持“长表上下文是主要干扰源，移除后即可修复”的简单解释，也没有验证内部机制。**

最后一组生成于 2026-10-09 14:11（北京时间）完成；流水线退出码为 0。两个模型均通过服务器端提示、评分、汇总重建，本仓库另提供便携离线复核。

## 为什么做、验证什么

V4 在显式输出正确数字后仍会选错；V3 的短数字提示却表现较好。一个待检验的简单解释是：原表仍在上下文中，干扰了后续比较。两轮协议不同，不能直接把分差归给长表，所以本轮固定同一份实际读数，只改变新比较请求是否附带原表。

如果移除原表是一种有效修复，应在完整配对样本上带来净收益，而不只是修好挑出的旧错题。这里同时看准确率、产率损失、修复与新增错误，以及最高/最低两个方向；没有把短提示效果好预设为结论。

## 比较了什么

固定每个模型自己在 V4 输出的四个数，保留数字原文、精度、别名和顺序，分别新开两个独立请求：只给四个数；给原表加同样四个数。两者都要求只比较给定的四个数，不使用旧选择答案，也不拿真值修正数字。

每模型 2,640 条 V4 来源响应、5,280 次尝试；其中 4 条来源数值无效，在两条件各记失败并跳过生成。两模型合计 **10,544 次新生成、16 次跳过**。新生成无非法选择、无输出截断。

## 每个对照为何需要

| 设计 | 方法与理由 |
|---|---|
| 两个条件都新开请求 | 在“仅数字”与“原表＋数字”之间控制请求边界；若只比较 V4 与新请求，就混入了重新作答的影响。 |
| 原样保留四值 | 从 V4 响应中截取数字原文，保留精度、别名和输出顺序；不按大小排序、不修正错误，避免悄悄改变比较输入。 |
| 同模型配对、只差表格前缀 | 基座用基座读数，普通 SFT 用自己的读数；两条件的比较要求相同，并打乱执行顺序。这样评价固定读数下保留原表的净效应。 |
| 全部来源响应入分母 | 既看原错误能否修好，也看原正确样本是否受损；上游无效数值在两个条件都计失败，避免只留下容易处理的样本。 |
| 同样读值→程序 | 程序对完全相同的数字取最大/最小，作为避免模型比较错误的参照；不把读值错误排除在流程外。 |
| 两套正确性评分 | 分别按原始实测真值、按实际给定数字评分，区分“选对化学表答案”和“正确比较所给数字”。 |

**方法性质：这是固定读数的配对上下文消融，没有新增训练算法。** 是否保留原表也会改变输入长度和 token 位置，所以它检验的是整个前缀的行为效应，不能单独识别注意力干扰或某条内部路径。

## 完整样本结果

每个条件准确率分母为 2,640，包括上游失败。

| 方法 | 原始模型准确率 | 普通 SFT 准确率 | 原始模型平均损失 | 普通 SFT 平均损失 |
|---|---:|---:|---:|---:|
| V4 同次读值再选择 | 93.33% | 94.73% | 0.5846 | 0.5256 |
| V5 仅四个数 | 92.54% | 92.61% | 1.0548 | 1.1382 |
| V5 原表＋四个数 | 93.30% | 95.11% | 0.3032 | 0.2570 |
| 同样读值→程序比较 | 97.73% | 98.45% | 0.1911 | 0.1157 |

损失为产率百分点，越低越好。V4 损失分母 2,640；其余按 2,636 条有效决策计算，不给失败虚构损失。V4 与 V5 的成对共同有效比较另存于原始记录的 `paired_contrasts.csv`。

对“是否正确比较了实际给定数字”单独评分，仅数字条件为 **94.43% / 93.67%**，保留表格为 **95.27% / 96.33%**（仍按 2,640 次尝试）。因此问题不能全部归因于上游抄错数值。

## 修复和新增错误必须一起看

主要对照是两个 V5 新请求之间的变化：

| 从“原表＋数字”改成“仅数字” | 原始模型 | 普通 SFT |
|---|---:|---:|
| 修复原错误 | 102 | 74 |
| 引入新错误 | 122 | 140 |
| 准确率变化 | −0.76 个百分点 | −2.50 个百分点 |

最大值任务的变化为 +0.23 / −1.59 个百分点，最小值为 −1.74 / −3.41 个百分点，不能描述成各子条件完全一致。

仅数字条件修复了 V4 正确读值错误中的 100/115、84/100，看起来很高；但相对 V4 全部原正确决策，又引入了 129、148 个新错误。只报告前一个比例会误导。

## 研究判断

- 保留原表相对 V4 的准确率变化为 −0.04 / +0.38 个百分点，平均有效损失下降；尚不是稳定的准确率优势。程序比较仍更强。
- V3 的短输入高分不能直接外推到 V5：来源读数、映射、输出顺序和提示协议发生了变化。
- 两个 V5 条件之间改变的是原表前缀，也同时改变长度和 token 位置。V4 与 V5 还改变了请求边界与作答方式；均不能识别某个内部电路。
- 这些呈现来自 165 个表格/目标组合、4 个组、一个来源；两个模型共享基础权重。没有按请求数计算伪独立显著性。

**取舍：该候选的现有版本停止推进，保留负结果。** V5 没有提供预期修复收益，结合 V1 未证明训练优势、程序基线更强、与课题要求仍有距离，不再默认追加格式诊断或机制训练。这个决定不等于证伪所有相关解释；重新提出须有新的具体科学问题、独立数据和近邻差异，见[候选记录](../../../候选IDEA集合/04-化学表格决策-已归档.md)。

新增生成耗时合计约 133.4 分钟，不含模型加载；复用了 V4 的读数缓存。部署为两步工作流时，仍应把上游读值成本算入。
