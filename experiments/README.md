# 实验归档

这里保存候选 04“化学表格决策”的 V1–V5 实验。**现有版本已停止推进，不代表已选定研究方向。** 取舍依据见[候选记录](../候选IDEA集合/04-化学表格决策-已归档.md)；其他候选尚无实验结果。

主要诊断对象是 **Qwen3-14B 与一次普通 LoRA 微调模型**。数据来自同一个 Buchwald–Hartwig 实验来源；V3–V5 使用 330 个验证任务、4 个添加剂组、11 张条件表。

每轮文档均说明**为什么做、验证什么、方法与对照为何这样设计、结果能支持到哪一步**。设计说明依据实现和冻结记录回溯整理，不追认预注册；算法候选、行为观察和模型内部机制分别标注。

## 每一轮回答什么

| 轮次 | 问题与方法 | 已有结果 | 入口 |
|---|---|---|---|
| V1 | 用五个选样/呈现训练臂检验：区分指定捷径的样本是否更值得训练？ | 当前实验不支持；选样还存在覆盖与难度差异。 | [设计与结果](results/v1/结果分析.md) |
| V2 | 拆分块间、块内、全表换序；独立检查抄值、条件关联与选择。 | 记录相邻时较稳；全打散明显下降；读值交给程序比较更强。 | [设计与结果](results/v2/结果分析.md) |
| V3 | 分别给正确四值、模型读数，或要求同次先读后选，检查比较步骤。 | 修复了大量直接决策错误，但仍有读对选错。 | [设计与结果](results/v3/结果分析.md) |
| V4 | 四种别名映射 × 两种输出顺序，区分位置、字母和化学身份。 | 呈现敏感真实存在；一个简单规则无法覆盖全部错误。 | [设计与结果](results/v4/结果分析.md) |
| V5 | 固定实际读数，在两个新请求中配对比较有无原表。 | 仅数字条件准确率更低、平均损失更高，不支持预期净修复。 | [设计与结果](results/v5/结果分析.md) |

这些是开发实验。旧测试集已参与方向选择，之后的方法确认需要新的独立数据。当前没有验证新内部机制，也没有验证新的训练方法优于强基线。

## 阅读结果前的三个约定

- 任务是在已给实测表中，按指定底物选产率最高或最低的配体。它检查有限表格上的条件选择，不直接检验化学因果规律或实验方案可实施性。
- 准确率衡量是否选到任一最优项；产率损失衡量选错的代价，单位为百分点、越低越好。非法输出和上游失败不从总体准确率中删去；损失的有效分母在各轮注明。
- 同一表格的最高/最低任务、多个排列和别名映射属于重复测量。请求数量不是独立样本数量；普通 SFT 与基座也共享基础权重。

```bash
# 在仓库根目录执行；只需 Python 3.11+ 标准库
python experiments/tools/replay_results.py

# 检查实验代码；缺少 torch 等可选依赖的模型测试会明确跳过
cd experiments/scientific-evidence-learning
python -m unittest discover -s tests
```

原始记录保留提示、响应、评分、协议和运行元数据。压缩包内的 `SHA256.json` 用于检查文件字节；这些哈希检查不能替代评分复算。模型权重与 adapter 未打包。

V1–V5 的实验实现、配置与原服务器脚本保持原字节。仅迁移了一个测试夹具的位置；历史服务器绝对路径保留在运行元数据中。当前复核没有重新训练或调用模型。
