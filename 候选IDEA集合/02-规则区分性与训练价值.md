# IDEA 02 · 规则区分性与训练价值

**问题：**一个样本能区分正确规则与多少竞争错误规则，是否能在难度和覆盖之外预测训练价值？

已有依据：原五臂实验中，高分歧没有胜过普通 SFT；高分歧只覆盖 32 个条件块，普通臂覆盖 39 个，难度分布也未完全一致。已有 CPU 审计表明更严格匹配的候选池可以构造，但尚未证明训练有效。

**继续条件：**先冻结样本价值指标，匹配来源、条件块、目标频率、答案分布、难度和 token 预算，再做多种子比较。

最低基线：普通 SFT、难例选样、合成多键检索、语义反事实训练。数据选择和新增损失函数分开消融，最终在新来源或新关系组合上确认。

可能的贡献是可验证的样本价值规律。若收益可以由难度或覆盖解释，就不能宣称规则区分性有独立作用。
