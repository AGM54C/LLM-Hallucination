# 候选 04 · 化学表格决策

**状态：现有版本停止推进，保留负结果。** 这是尝试过的一个候选，不是已确定的研究方向；不默认接着运行 V6 或扩大训练。

## 尝试过什么

从真实反应表中检索指定条件的四个产率，选择最大或最小值。曾考察分歧选样训练、顺序与标签扰动、显式读值，以及去掉原表后的再次决策。盲样查询是该候选的配套设想，尚未形成独立方法收益。

## 为什么停止

| 依据 | 对取舍的影响 |
|---|---|
| V1 高分歧选样未胜过普通 SFT，覆盖和难度也未完全匹配 | 没有支持新的选样训练优势。 |
| V4 发现读值正确而选择错误，但随呈现变化 | 证明了行为错误，尚未定位内部机制。 |
| V5 移除原表后，准确率净降 0.76 / 2.50 个百分点，平均损失增加 | 不支持“去掉原表即可修复”的预期。 |
| 同样读数交给程序比较，准确率为 97.73% / 98.45% | 简单强基线更好，增加模型环节的价值尚未证明。 |
| 已有工作覆盖条件使用、读出与决策分离、局部干预和反馈学习 | “读得对却选错”或“再加训练”本身不是新贡献。 |
| 任务是有限表格检索与比较 | 与科学机理约束、因果一致性和实验可实施性仍有明显距离。 |

## V5 排除了什么

两个 V5 条件都重新请求模型，使用完全相同的上游读数，仅比较有无原表前缀。只给数字的准确率为 **92.54% / 92.61%**，保留原表为 **93.30% / 95.11%**；顺序为原始 Qwen3-14B、普通 SFT。

结果否定了这组实验中预期的净修复收益。前缀变化同时改变长度和位置，两模型有关联、数据只有一个来源，因此不能推广成“上下文永远无害”或“所有内部机制假说都错误”。**但没有排除全部可能解释，不是继续投入的充分理由。**

如果将来重新提出，应先说明新的科学约束问题、独立数据和区别于现有方法的可检验假设，再作为新版本评估。仅发现更多数字或标签错误，不构成恢复优先级的依据。
