# 候选 IDEA 集合

更新：2026-10-18

科研智能体自我改进后的任务成绩上升，仍不足以说明它更善于识别推理缺陷、开展有效验证和修正错误。
我们研究 RSI 前后这些能力的变化，结合 Agent 轨迹诊断与执行模型内部诊断，分析反复出现的失败条件。
通过针对性干预和独立任务检验，评价诊断能否减少错误复发，帮助系统形成可迁移的改进。

## 三个研究切口

| IDEA | 核心问题 | 在主线中的位置 |
|---|---|---|
| [01 · RSI 是否改善科研推理可靠性](01-RSI是否改善科研推理可靠性.md) | 自我改进后，系统在哪些推理、验证和纠错环节变好，哪些错误仍然存在？ | 先开展的评估与分析。 |
| [02 · Agent 与 LLM 联合诊断科研推理错误](02-Agent与LLM联合诊断科研推理错误.md) | 轨迹诊断与执行模型内部诊断能否相互补充，并指导可验证的干预？ | 解释失败条件，检验内部诊断的额外价值。 |
| [03 · 诊断指导的科研智能体自我改进](03-诊断指导的科研智能体自我改进.md) | 把诊断结果用于选择改进方式，能否减少后续任务中的错误复发？ | 在评估和诊断成立后验证方法收益。 |

三个切口属于同一研究主线，可根据结果确定论文贡献，不预设需要分别完成三篇论文。

## 研究范围

聚焦科研过程中的假设检验、实验设计、计算分析、因果推断和结果解释，关注推理失当、无依据确认、无效验证和修复失效。明确标记的待检验假设保留探索空间；其所依赖的已知前提和推导仍可接受检查。

当前主线是评估、诊断与错误后的修正。GraphRAG 可按任务需要组织数据关系，其作用作为实现因素单独检验。具体学科与任务族在小范围试验后确定。

RSI 实验需要说明实际改进对象是参数、技能、记忆、控制代码还是改进程序本身，并记录更新与验收方式。普通反思、外部 RL 训练、跨任务自我改进和改进程序的递归增强分别报告。

## 真值未知时如何评价

| 任务条件 | 可以评价什么 | 结论边界 |
|---|---|---|
| 有参考解或确定性检查条件 | 计算、实现、约束满足及修复结果。 | 用于受控机制检验，不能直接代表开放科研能力。 |
| 最终结论未知，但部分推断条件可检查 | 推断是否超出实验的识别能力、验证是否独立、反证是否被处理。 | 判断相对于明确条件的推理有效性，保留未决部分。 |
| 后续能够获得独立观测或实验结果 | 预先提出的预测表现、证据更新后的结论修正和研究推进。 | 单次观测仍有噪声与适用条件，不等于最终理论获证。 |
| 缺少可检查条件和可检验后果 | 记录争议及待补信息。 | 不给出强制正误标签，不宣称该部分幻觉减少。 |

判断依据优先来自明确的科学条件、独立执行与观测；专家复核需保留依据和分歧，模型评判需接受抽样审计。判断推断当时是否有依据，按该步可得信息评价；后续观测用于检验预测和修正。所有结果同时报告可评价覆盖率、未决比例、误报、任务推进和成本，防止用大量弃答换取较低错误率。

## Tev 的启发

[Tev](https://arxiv.org/abs/2610.18868v1) 从已知正确的隐藏环境状态生成任务、检查器和过程奖励，说明中间进展也可以形成可靠的学习信号。其 latent world 指环境真值；过程分数主要评价工作区产物，不能直接解释执行模型的内部机制。

附录图 7 的科学计算案例中，基础模型让两种计算方法共用错误的算子表，并把结果一致当作验证成功；Tev 的示例轨迹采用独立构造进行核验。该案例提示可以研究“自我改进是否改善验证的独立性”，但单个案例不足以证明普遍改善。

借鉴其环境与评价依据的一致性设计，将可控任务用于诊断核验，再在结论开放的真实科研任务上检验可判定环节和后续表现。Tev 的 RL 结果本身不构成 RSI 已实现递归增能的证据。
