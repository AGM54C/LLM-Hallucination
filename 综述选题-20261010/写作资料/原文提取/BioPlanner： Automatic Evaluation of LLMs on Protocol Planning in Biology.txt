loop, and then manually reviewed. Generated pseudofunctions are used to define the admissible action space in
downstream evaluation tasks, and pseudocode instructions using the pseudofunction calls are used as ground truth
to measure the accuracy of generated code in downstream tasks, enabling automatic evaluation.
