## 问题与主张：摘要、引言、相关工作（pp.1—2）

作者直接介入 Yue 等“RLVR 主要激活已有路径”的争论。它提出一种兼容解释：单步基本技能本来存在，但多步组合的成功概率极低；RL 只要提高基本步骤成功率，就可能使以前在有限预算中解不出的组合题变得可解。因此作者把这种变化称为“新能力”，同时承认它未必引入新知识。

这篇论文的有用之处是把“新知识”“新原子操作”“新组合的实际可解性”分开；其风险是随后使用了比有限采样证据更强的“不可能”“topological disconnection”等措辞。它不是对自然科学中未知事实可以凭空生成的论证。

相关工作指出另一条直接近邻：Yuan 等 *From f(x) and g(x) to f(g(x))*（2509.25123），以及 Cheng 等 *From Atomic to Composite*（2512.01970）。本轮对前者另核对了 arXiv 元数据与摘要，但未全文阅读；不能把本文引用当成已独立核验它们的实验。

## pass@k 的分解（§3，pp.2—3）

令正确性检验器为 `V(y,q)`，单题成功率为 `p(q)=E[V(y,q)]`。在固定策略和独立采样假设下，单题至少成功一次的概率是 `1-(1-p(q))^k`，数据集分数是该表达式对题目的平均。这是概率恒等式，说明 pass@k 取决于整个逐题成功率分布，不能仅用平均 pass@1 推断。

图 1 使用两题的玩具分布展示曲线交叉：一些题的概率提高、另一些题的概率下降时，小 k 改善与大 k 退化可以同时出现。因此清华观察的覆盖收缩，并不必然要求“所有题都变差”或“从来没有任何新解题增益”。

§7.1 用同一批 128 次采样估计逐题 p，再展示该公式与经验 pass@k 的拟合。这主要是指标关系的自洽核查，不能当成对某种内部推理机制的独立因果验证。

## “能力”的操作化定义（§4，pp.3—4）

作者区分 Null Set、Feasible Set 及二者之间的过渡区：

| 定义 | 文中阈值 | 证据允许的解释 |
|---|---|---|
| Null Set | 128 次未成功，以 rule of three 取 ε≈3/128≈0.023 | 在该采样设置下，成功率的单侧 95% 上界约为 2.31%，并非 p=0 |
| Feasible Set | δ=1/8=0.125 | 8 次采样的期望成功数至少为 1；不等于 8 次必然成功 |
| 实证 emergence | base 的 Avg@128=0，RL 的 Avg@128≥0.125 | 从本轮未观测成功到较可靠成功的有限预算跃迁 |

原文 p3 将 Null Set 称为模型 reachable hypothesis space 的“topological disconnection”；p4 说 correctness “effectively a zero-probability event”。这些是过强解释。普通有限采样不能区分严格零与很小的正概率，尤其尚未遍历提示、温度和截断设置。

本轮仅做解析数值核对：若 p=0.125，8 次至少成功一次概率为 **65.64%**；作者的“期望次数≥1”公式正确，但随后从它推到稳定能力、排除幸运猜测，仍需要额外论据。有限预算能力定义本身可以使用，只需明确它是约定的门槛。

## 机制假说及代价（§5，p.4）

作者把 M 步推理的成功率近似为原子步骤成功率的乘积，**明确假设各步骤正确性独立**。例子从 `0.3^5≈0.00243` 提高到 `0.7^5≈0.16807`，因此单步增益可能产生很大的组合效果。这是值得借鉴的机制假说：可靠组合可以通过提高基本步骤可靠性而获得，无须引入新的基本算子。

但该乘积不是一般推理的无条件定理。真实链式推理的精确分解应涉及在先前正确条件下的条件概率；在地面真值中间状态上单独测得的边际成功率，不一定等于模型自行生成轨迹的条件概率。不同步骤可能共享错误、互相纠错或走替代路径。

原文 p4 说 p≈0.0024 “empirically results in zero successes (Pass@128=0)”。算式本身只意味着：128 次至少一次成功仍有约 **26.76%** 概率，1024 次约 **91.72%**；不是必然观测零。这个例子恰好说明预算定义与绝对 support 边界必须分开。

§5.3 认为全局期望奖励优化可能牺牲少数任务，称为 capability erosion。这种非单调性是合理风险，也得到后文散点图支持；但“优化总体奖励必然以破坏少数技能为代价”并未由目标函数单独证明。

## 实验设计与外部信息（§6，p.5；附录 A、B，pp.11—12）

Algebrarium 根据人为规定的代数规则生成合成任务，降低题面记忆污染，控制运算深度。四域分别为：整数上的加密导航、三个模 26 转子的直积、两个生成元的自由群式字符串约简、魔方动作序列的规则约简。训练仅包含 1 次二元操作，每域 3200 题，共 **12800**；测试每域 200 题，共 **800**，按 2、3、4、5 次操作分层，每层总共 200 题。

评估六个模型：Qwen3-4B、Qwen3-4B-Instruct-2507、Llama-3.1-8B-Instruct、Llama-3.2-3B-Instruct、Gemma-3-4B-it、Gemma-3-12B-it。附录 B.1 将一个 Llama 写为 3.1-3B，与图例的 3.2-3B 不一致；本记录遵循主要图例，实际复现前应核对 checkpoint。

GRPO 100 步，verl / vLLM，AdamW 学习率 1e-6，global batch 128，minibatch 8，rollout group 8；prompt 上限 1024，response 上限 8192。KL 系数 0.001 仅监控，不进入优化目标；advantage normalization 关闭。最终 `boxed` 答案 exact match；文中未清楚列出用于 128 次评估的温度/top-p，也未报告多训练随机种子的区间。

外部信息来自**生成器规定的规则、任务与正确答案，以及确定性检验信号**。没有报告 RL 时从更强教师直接提供整条组合题答案，但这仍不是无外部信号的自我改进。固定规则可作为学习约束，不等于模型有权自创科学前提。

## 核心结果与图核查（§7，pp.6—8；附录 B.3，p.12）

1. **图 2，p6**：六模型在 k≤128 的曲线中，RL 均优于起点。图标注 pass@128 差值依次约为 Qwen3-4B +15.8 pp、Qwen3-Instruct +2.3 pp、Llama-8B +36.4 pp、Llama-3B +23.5 pp、Gemma-12B +21.0 pp、Gemma-4B +16.0 pp。这是有限预算下组合题泛化的实际正证据。
2. **图 3，p6**：作者汇总 base 128 次没有成功的条目，其中 **22.6%** 进入 Avg@128≥0.125 区域；这一子集训练后平均成功率约 **0.60**。图中心显示 2567 “Impossible Tasks”。因为单份测试仅 800 题，应避免把它写成 2567 道不同题；很可能是跨模型汇总的题目-模型条目，论文没有在图注中清楚展开汇总规则。
3. **图 4，p7**：成功率随运算深度下降；RL 曲线下降较慢。支持“误差积累与组合难度有关”，不证明所有任务都服从同一独立乘法机制。
4. **图 5，p7**：训练后 joint-step 与整体 outcome 的 Pearson ρ 为 0.69—0.96。图形仍有明显偏离 y=x 的散点，尤其 Gemma-4B。相关性支持预测关系，不能单独证明内部推理过程的因果机制。
5. **图 6，p8**：整体原子技能增益伴随部分负向迁移；Llama / Gemma 存在已较熟练原子题退化，Qwen 较轻。这与清华观察的“部分题可解性下降”能够共存。
6. **图 7，p12**：奖励提升时输出熵下降。至少在该受控任务中，熵下降并没有阻止大 k 增益。因此不能把平均 token entropy 的升降直接当成能力边界的充分指标。

细节核查：图 2 图注声称 MSE 一贯小于 1e-4，图中却标出若干 base MSE 为 3.3e-4、3.1e-4、5.8e-4 等。它不推翻正向覆盖结果，但说明图注概括应校准。

## 附录领域规则逐页核查（附录 C，pp.12—15）

- p12—13 加密导航：七进制 a—g 映射 0—6，FWD/BACK 表示符号；例子 FWD(ad)+BACK(ef)=BACK(ec)，算术 3−33=−30，与编码一致。
- p13 Enigma：实为三个独立的模 26 加法，不包含真实 Enigma 的进位/机械过程。例子 A,C,Z 与 B,B,C 相加得到 B,D,B。结论应限于给定合成运算。
- p13—14 knitting：k,p 与 K,P 互逆，连接后反复消去相邻逆对；kpPK→kK→空串。它给出可检查的原子转写规则，是科学验证器组合实验可借鉴的任务构造方式。
- p14—15 cube sequence：逆元抵消、同面模 4 合并、相对面按优先级交换；示例 `inv(R U) · R U R# → R#`。本文测试的是所定义约简规则。仅凭列出的这几条规则，不宜宣称已经完整刻画物理三阶魔方群的全部等价关系与唯一规范形式。

## 对当前科学验证器课题的启发与限制

最有证据的启发是：先把检查/修复任务拆成能够独立验证的原子动作，再测试对未训练组合的可靠迁移。科学场景的原子动作可以是单位核查、代数等价检查、边界条件匹配、前提来源核查等；这里是研究设想，本文未验证这些具体科学任务。

可推翻问题：在**固定允许前提与推理规则**下，原子检查练习能否提高未见组合错误的检测/修复率，同时不增添未授权前提、不损害旧题？评价应包含逐实例成功率与区间、固定预算的覆盖曲线、原子/组合迁移以及 regressions。要用整条证明/推导检查器排除“终局答案正确但过程错误”。

本文不能支持：模型产生新的科学事实；新基本推理算子从零出现；一般推理都服从独立乘法规律；无限持续 RSI；开放科学检验器可以只靠最终数值判真。它与“RL 往往重分配已有技能的成功概率”并不逻辑冲突，因为可靠组合本来就是它提出的新能力来源。
