## 研究问题与方法

本视角检查三个问题：自改进究竟改变何种对象；验证信号对持续改进起什么作用、有哪些反例；这能否支持一个禁止无依据扩展科学前提的验证器。先用 OpenAlex 广检索直接 RSI / self-improving AI 综述，再沿 evaluator、verification hierarchy 及精确题名窄检索，并用 Crossref 交叉搜题名。筛入核心的原因是本篇直接把 evaluator 作为独立改进对象，兼述支持研究与失效研究。最新检索日期为 2026-10-14，具体日志见 `search-log-and-synthesis.md`；检索不是系统性穷尽。

## 逐节阅读

### 1. 引言（pp.1–2）

作者用 Good、Gödel machine、FunSearch、AlphaEvolve 串起概念史，但把当代工作分成：改输出、改训练数据/权重、改 agent scaffolding、改研究流程。引言对 Anthropic 关于 RSI 的文章有一项关键限定：它只提供动机与阶段词汇，**不被当作学术证据**（p.2）。类似“实验室多少代码由模型写出”的宣传性数据不能转写成综述独立证实的事实。

中心论点是 evaluator 反复成为瓶颈。语料总数 1,250、74% 在 2026 年发布（p.2）描述的是作者取得的样本，不能直接代表全领域人口分布。该论点是后续综述的组织判断，并非“可靠验证充分且必要”的定理。

### 2. 定义、分类、语料方法（pp.3–6）

作者把 **verifier** 限定为具有 soundness guarantee 的评价器，把无此保证的学习/提示评价器称 **judge**（p.3）。在讨论科学幻觉检测器时，这个用词区分有用：一个模型给出的“已核实”标签并不会自动获得形式 soundness。

最重要的定义选择在 p.4：

| 术语 | 本文采用的含义 | 使用时的限制 |
|---|---|---|
| bounded self-refinement | 相对固定外部 evaluator 改进 | 这是该综述的定义；不能由名称推出这种循环没有持久收益 |
| open-ended RSI | 改系统，也改评价标准/改进机器，且没有固定外部锚点 | 不能套用到所有把“改进算子本身可改”称为 RSI 的论文 |
| deployment-time evolution | 冻结权重改输出、在线调权重、改 harness/技能/记忆 | 是否持久与是否训练不是同一条轴 |
| training-time iteration | 自生成数据、奖励、教师信号更新权重 | 信号可能自生成，但不等于无外部信息 |
| self-evaluation | 改进 judge、verifier、reward、rubric | 必须追问哪个层面允许改、谁验证修改 |
| Auto Research | 改进研究过程本身 | 自动执行研究不自动等于自主确定研究目标 |

另一条轴是 human-in/on/closed loop（p.4）：人逐次审核；机器评分但人审计部署；无人工逐轮审批。**无人逐轮审批不等于没有人提供目标、规范、环境或真值。**图 1（p.6）用 4×3 网格列例子，图中仍把固定环境下的 DGM 等放进 closed loop；所以“闭环”“open-ended”“无外部锚点”不能互换。

作者自己承认分类的两个盲点（p.5）：默认目标已经给定；以改进载体为单位，不能表达同一系统跨阶段累积方法的连续性。此处对科学工作流尤其重要：局部检查通过并不说明问题仍值得研究。

语料方法是 871 篇 seed harvest 加 379 篇针对 evaluator、TTT、zero-data self-play 的补检索（p.5）。分类依据主题、题名摘要关键词及单名标注者人工修正，不是 1,250 篇都以同一严格程度全文评审。p.6 明示样本非 census、深度上限与近期偏倚、工业实践不可见；约 54/379 篇补充样本属于 peripheral query bleed，仍计入数量但不当作证据。不能拿 1,250 这个数字充当该综述全部结论的证据强度。

表 1（p.3）的五类数量为 393 / 340 / 318 / 139 / 60，合计 1,250。图 2（p.7）是摘要 TF-IDF → SVD → t-SNE，可视化文献语义位置；坐标没有能力含义，类别重叠也不是因果证据。

### 3. 部署时自演化（pp.6–13）

**输出精炼（§3.1–3.3，pp.7–10）。**作者从 generate–critique–revise 出发，区分结构化/符号反馈、搜索式精炼与模态差异。诊断性研究转述指出，改写可能主要改善流畅度、风格和术语，而非语义充分性（p.8）；模型可能把初稿推向自己的分布。该页同时承认：重查明确约束时，intrinsic self-correction 仍可能有价值。不能把“无反馈通常不可靠”升级成“任何内生精炼都无效”。

代码/形式数学是较清晰的验证场景（p.9）。作者强调要分开真实反馈收益、重新采样、格式纠正和额外推理计算，否则 naive improvement 会夸大。单元测试只给局部反例，诊断粒度也重要；FLARE 提供行级可疑位置，CoSPlay 联合演化代码与自写测试，后者暴露“验证器也可能与生成错误共变”的问题（p.9）。这直接支持科学验证器应给出**哪一步、哪个依赖、哪项证据不足**，而非只输出一个总分。

多模态中，self-consistency 可能优化答案一致性却弱化图像条件依赖，learned judge 也会有不同感知盲区（p.10）。因此不能把模型间一致当成独立科学证据。

**TTT（§3.4，p.10）。**模型在部署时改权重，属于时间尺度上的中间态。一次任务内部修正、会话内权重变化、跨任务技能积累的持久性不同。图 3（p.8）明确画出这个 persistence 轴；“迭代了多轮”还不足以说明下一轮/下一任务的改进能力提升。

**Harness / agent evolution（§3.5，pp.11–12）。**Gödel Agent 改运行代码；Darwin Gödel Machine 以经验基准验证代替收益证明；其余工作分别改 prompt、评价、拓扑、数据或基础设施。p.11 列出 DeepVerifier [61]、Red Queen Gödel Machine [62]、Escher-Loop [63] 等最接近 evaluator 或 improver 自改进的路线，但不能只凭其“self-evolving”名字判断究竟修改了 rubric 还是反复修正了任务答案。原始元数据核验见后面的近邻表。

p.12 提醒增益与计算成本分不开；综述转述的一项 34 配置 Pareto 分析中，峰值 +7.1 点对应约 20 倍计算。这里不是本次测得的数字，也不应跨任务泛化成所有多代理方法的固定成本。

**技能库和累积（§3.6，pp.12–13）。**作者报告人写技能与 LLM 自写技能之间存在差距，把 evaluation-guided revision、可审计 rubric、可形式验证 skill contract 视为改进载体。持久错误会传播到后代和共享库；因此“能累积”同时意味着“错误能固化”。对本课题的直接启发是：新检查规则应带来源、适用条件和验证凭据，不能因为某次流程成功就升格为普遍科学规律。

### 4. 训练时自迭代（pp.13–16）

图 4（p.13）统一 Model → Generate → Evaluate/Select → Update weights；不同范式主要区别是评价信号来自哪里。这个抽象提醒研究设计同时审查生成、准入和更新，而不只审查终局 reward。

**Self-reward RL（§4.1，pp.13–14）。**ReST-MCTS* 被用于说明“终答正确也可能推理错误”；SEVA 把验证输出结构化为证据对齐、推理链、置信度。STV 被提出为两个位置的共同改进对象：test-time V–R loop 与训练数据筛选。综述把“自训练 verifier 是否真正打破循环”保留为问题（p.14），并没有宣布已解决。

同页给出重要反例：有真实可验证二元代码奖励，REINFORCE 自训练也会先升后崩，KL/EWC 约束未必阻止。因此**可靠目标信号不充分保证优化过程稳定**。另一个失败是 scientific amnesia：行为改善而实验方法不积累。它支持把下一轮改进效率与当前 pass@1 分开测量。

**CoT self-training（§4.2，pp.14–15）。**STaR 过滤正确终答；反思可以修复失败样本；无外部 reward 的 LaTRO，以及只用无标注问题的 self-verified distillation，也在综述中占有正面位置。p.15 的反例又指出“能执行可验证搜索”不自动意味着能从轨迹内化该程序。需分开任务可验证性、模型表达能力与可学习性。

**On-policy self-distillation（§4.3，pp.15–16）。**privileged teacher 是同一权重但看到参考解、已验证反馈或更丰富上下文的模型，故“没有外部 teacher 模型”不等于“没有外部信息”。正文还引用不依赖 verifier 的 simple self-distillation 取得代码增益（p.15）；与此同时，teacher privilege 可诱发风格漂移、前缀问题、视觉捷径以及域内偏倚。这些材料不支持“有验证就一定新能力、无验证就绝无改善”的二分。

**Self-play（§4.4，p.16）。**任务/对手也由模型产生，可构建课程，但任务准入、奖励依据、任务多样性和模型一致性会相互作用。此处综述的概括需要校正：它把 [120] 叙述成 data gating 与 reward grounding 任一失效都会崩；原始 arXiv 摘要明确报告的是**所测条件下严格 gate 对所有 reward 变体均足够稳定，包括不接触真值的 self-consistency reward；去掉 gate 则无 reward 变体足够**。原文尚未全文精读，因此这里用来限制综述概括，不当作已复核的定理。

**Embodied / data loops（§4.5，p.16）。**物理反馈昂贵、延迟而且有噪声；DataEvolver 把数据制备流程本身纳入改进。对于科学验证器，“可检查”仍须明确检查成本、何时可获得结果、是否有测量噪声。

### 5. 自评价：全篇核心（pp.17–21）

**设计空间（§5.1，p.17）。**包括 PRM、LLM judge、rubric、meta-evaluation 和 evaluator co-evolution。评价对象可从整个答案细化为二元可审计问题、证据对齐、过程步骤。模型 judge 的平均人类一致性不等于在目标领域或被优化后仍可靠。

**验证层级（§5.2，pp.17–18，图 5）。**从形式 verifier、execution feedback、learned judge 到 intrinsic signals，形式保证逐渐弱化、任务覆盖逐渐变宽。图 5 顶上还有虚线 human research judgment 框，但文字特别说明，**选择要评估什么在这个层级之前，不是形式证明之上再加一层万能判官**（pp.18、20）。

最必须保留的原文校准是 p.18：这个“改进强度随验证层级变化”的关系是 **“a qualitative pattern … not a measured law”**。它是综述综合判断，不是控制变量后的统计规律，更不是无法反例的必要充分条件。

p.17 声称形式 verifier 的 soundness 可避免接受 false improvement；用于科学工作流时要补上本文未展开的限制：形式证明只证明**已给形式化问题、假设和受信内核之下的结论**；它不检验形式化是否忠实于科学主张、实验测量是否可靠、前提是否被暗中扩充，也不保证更正确的程序成本更低或泛化更好。这是本次阅读作出的逻辑区分，而非该综述已经建立的完整科学验证方法。

**四类失败（§5.3，pp.18–19）。**

| 失败 | 原文机制 | 对受限科学验证器的含义 |
|---|---|---|
| self-confirming loop | generator/evaluator 共用偏倚，高信心错误得到更高回报 | 独立提示、多模型投票不能自动视作独立证据 |
| model collapse | 尾部分布丢失、信息缩减、误差积累；混入外部信号等可改变结果 | 不能从一次过滤成功外推无限轮稳定 |
| diversity collapse | proposer 收缩到奖励偏好的窄任务带 | 必须测新错误类型和新条件覆盖，不能只看同分布通过率 |
| frame lock-in | 稳定、诚实、接地的循环也可能持续优化一个已失去价值的问题 | 科学问题选择与局部推导验证是不同职责 |

作者对 collapse 的讨论同时呈现悲观理论与工程缓解；没有给出最小外部信息率（p.19）。不能从若干有假设的 impossibility result 得出所有自训练都不可能超越基础模型。

**不可直接验证的边界（§5.4，p.20）。**作者区分 direction evaluation（给定候选判断严谨性/值得投入程度）与 direction generation（构造候选问题空间，发现目标已经过时）。SoundnessBench 被用作前者的诊断线索，而非后者已可测/可解的证据。把科学验证器设计成“给定声明和证据，判断可推出什么、缺什么”，比许诺自动判断科学重要性更匹配这一边界。

**结果改进与过程改进（§5.5，pp.20–21）。**作者倡导从终答分数转向错误记忆、过程反馈、技能、经验图、长期方法积累。此处“结果是运营费用、过程是资本支出”的比喻有启发，但不是普适成本定理；结果监督也能更新权重并泛化。可操作的研究问题是：修复记录在之后独立任务是否减少同类错误，以及这种收益相对存储/验证成本能否摊销。

### 6. 自动科研（pp.21–24）

**进化程序发现（§6.1，pp.21–22）。**FunSearch/AlphaEvolve 的强结果依赖候选是程序、可运行和可自动评分，收益还可能反馈到 AI 基础设施。作者也指出更好的搜索档案、资源分配、失败处理和路由能带来收益，不能一律归因为底座能力自我跃迁。

**AI scientist（§6.2，pp.22–23）。**当前构造性回应包括可组合研究 primitives、环境工程、把 claim/provenance/ablation/repair 等外化成可检查工件。综述把 A-Evolve-Training 作为接近闭环开发的例子，转述其发现 dev metric 与外部目标脱钩后更改搜索策略；同时明确目标和搜索空间仍由人给定。这一事件更像“借助外部性能检测内部代理目标失效”，不能据此证明系统可无锚点地自证进步。

**诊断文献（§6.3，pp.23–24）。**关键问题是：生成了论文不代表贡献可靠；只看文稿的评价可能比同时查工件更乐观；任务完成压力下可能生成缺失数据；正确终答可伴随错误机理；发表偏倚可被自动科研放大。p.24 明确应把 outcome、mechanism fidelity、epistemic honesty 分开测。

对于本课题，终局标签“对/错”不足够：至少还需检查假设来源、条件域、机制推断和是否承认证据不足。原文中相关批评有 position paper 和小规模诊断研究，不能全部当成广泛重复验证的结论。

### 7. 理论、边界、安全（pp.24–26）

积极条件包括反馈信息足够且与目标一致、经验覆盖足够、模型容量足够（p.24）；这些条件本身已说明 sound verifier 单独不充分。随后介绍可计算性、动力学、经济、信息论四种边界；p.25 对 compute–labor substitution 的不同建模规格给出相反方向结果，说明边界判断依赖假设。

本轮没有全文精读被引理论论文，故只记录它们在综述中的角色，不采纳“任何 LLM 都无法产生新能力”之类泛化。尤其 p.25 明示这些悲观结果**并不约束 bounded self-improvement + human direction 的影响**。受限验证器支持有条件的长期工程进步，与“不证明无界智能爆炸”可以同时成立。

关于 self-modification，安全内核若在 agent 能改的地址空间里，就可能被改掉（p.25）。对应科学工作流的设计推论是：可演化候选检查/搜索策略，和不得偷偷扩大可采信前提的规则，需要分属不同权限层。这是工程启发，不能仅凭该架构形式就宣称保障真实科学正确性。

### 8–9. 讨论、开放问题、结论及数据（pp.26–30）

图 6（p.27）用 seed corpus 展示论文增长，到 2026Q2 约 501 篇；早期 July 2026 cutoff 导致 Q3 不完整被省略。该图只描述 seed harvest，补检索有显著定向性，不能混用为总体时序。

p.28 认为 evaluator co-evolution 是多个子领域共同应对瓶颈的策略；同时承认它可能只是给 self-confirming loop 多套一层，并未证明“所有静态 verifier 都不能监督越来越强系统”。形式 proof checker 可以保持固定，而被检验命题、搜索策略、候选技能不断变复杂；问题在其覆盖与规范忠实性是否足够。

六个开放问题（pp.28–29）：最低外部 grounding；不可验证任务的可靠评价；循环稳定性；可信累积；可审计改进测量；识别应该改写问题框架的时刻。对最后一项，作者提出 productive abandonment、invariant transfer、absence sensitivity、reframing latency。这些是候选测量建议，尚不是本文实施并验证的基准。

结论仍把可测的 bounded 工程进步与 open-ended RSI 分开（pp.29–30）。数据仓库在 p.30：<https://github.com/deepgrounding/recursive-self-improvement>。本轮没有逐项复核其 1,250 条语料或仓库脚本，不能称复现语料分析。

## 对当前科学验证器想法的有条件综合

1. **得到支持的研究方向是“受约束地累积可复用检查能力”。**证据链来自 pp.11–13 的可审计持久载体、pp.17–20 的验证信号与失败模式、pp.20–21 的过程累积。它允许不断发现新的推导、组合已有规则、搜索更好的反例和检查策略；“不发明未经验证前提”并不等于“不产生新的演绎后果”。
2. **受限验证器不充分保证持续变强。**至少还存在优化崩塌（p.14）、表示/可学习性限制（p.15）、经验覆盖和课程收缩（pp.16、19）、目标框架失效（pp.19–20）。因此下一步应问“在哪些约束与反馈预算下能多轮可靠改进”，而不是问“有了 verifier 是否就解决 RSI”。
3. **固定信任内核与可演化检查器并不矛盾。**可让系统提出新错误模式、候选规则、反例搜索程序；只有当其适用条件和验证凭据被独立检查后，才准入持久库。若涉及新的实验事实，应记录为外部证据更新，而非冒充旧前提下的纯推导。这是基于阅读提出的设计假说，本文未直接实现这个科学场景。
4. **严谨性约束不应导致一律拒绝未知。**应区分“已由给定证据支持”“缺少某前提/适用条件”“可检验假设”“现有证据反驳”。如果只追求少接受错误而无限拒绝，难以验证有用的改进。该点需实验评价，不能仅由综述获得。
5. **不要把 evaluator co-evolution 自身当作新颖性。**DeepVerifier、RQGM、Escher-Loop、STV、VASO、claim-level auditability 和 deterministic integrity gates 都是需细读排重的近邻。RQGM v3 已另行全文读完40页，见 `rqgm-2606.26294v3-reading-notes.md`；其余原始入口本视角只做元数据核验。

建议能推翻设想的实验问题：在固定真值/形式前提核、相同模型与预算下，允许累积经验证的检查规则，是否比静态检查器更早发现新流程中的错误？是否优于直接更多采样/更多验证预算？若新增检验器只是压低接受率、对新科学条件不迁移，或凭据本身偷换前提，则“持续可用改进”假说应被否定。

评价至少分开：错误接受率、正确工作流保留率/覆盖、前提擅增率、证据链可重放率、跨任务迁移、每轮边际收益、成本和回滚频率。额外隔离终答正确、机理忠实与诚实弃答（pp.23–24）；结果曲线不能只报告最后一轮或最好的一轮。

## 阅读后仍未解决的问题

- 原始实验中 verifier 错误、数据 gate、分布覆盖和计算预算如何分离？综述无法替代方法与消融细节。
- 形式规范/前提从自然语言和实验材料转写时，如何约束翻译错误与适用范围遗漏？本文只提出 verifier 层级，没有解决科学语义落地。
- 什么叫“更好的下一轮改进能力”，怎样与更多算力、更多新证据、更强外部模型的收益区分？需要明确干预/对照。
- 固定可信核允许哪些扩展，如何在需要新事实时正当地引入外部实验，而不以“约束推导”为名拒绝一切新科学知识？
- 任务重要性、frame revision 和外部世界变化由谁发现？局部可检查性不足以覆盖这些职责。
- 本综述语料 cutoff 是 early July 2026，9 月修订仍不代表覆盖至 10 月。9–10 月的 RSI 系统结果、RQGM v3 等可能改变某些“最接近闭环”的比较，须另读原始论文。
