## 1. 问题、改进对象与固定边界（正文 pp.1–4）

传统 DGM/HGM/HyperAgents 固定评价准则，只改任务 agent 或 meta-agent。RQGM 的问题是：在评价昂贵、静态代理标准饱和或容易被利用时，能否让 evaluator 同时演化，同时避免新旧评价尺度混用。

RQGM 搜索的是**可编辑代码库树**：每个节点含 task agent、evaluator 和负责改代码的 meta-agent。它们可共享代码；只有 scoring 和 orchestration harness 固定（p.3）。它不是让底座模型无依据地修改所有真值，也不是本文做了 LLM 权重自训练；机器人 reward-design 分支另由固定 host 训练 PPO 策略，须与 LLM 自身权重改进区分。

归纳其权限结构如下：

| 层 | 允许变化 | 谁给合法性/选拔信号 |
|---|---|---|
| 候选任务 agent / reviewer / grader / meta-agent | prompt、工具、代码、部分运行参数与自改进流程 | 固定 scoring/orchestration host 的验证分数 |
| 当前实际使用的 evaluator | 一个 epoch 内冻结；只在 checkpoint 可更换 | evaluator-independent objective/human-label anchor；某些实验另叠加 adversarial pool |
| 固定评价入口 | 数据划分、评分/调度框架、预算等由外部给定 | 不是候选 agent 自己改写的对象 |
| 最后报告的证据 | held-out 测试；论文/证明还使用固定模型 panel | 此层仍有样本量、judge 偏倚和形式真实性限制 |

因此，“评价者可改进”与“保留固定外部准则”在这个系统中共存。它正好说明 Chen 综述将 open-ended RSI 定义为“无固定锚点”并非所有 RSI 论文通用的定义。

## 2. 搜索、冻结、更换与记录失效（正文 pp.3–4；附录 B pp.18–20）

搜索沿 HGM 框架在 expansion 与 evaluation 之间分配预算。选择扩展父节点使用 clade metaproductivity（整条后代子树的成功率），评价节点则用其自身统计；UCB-Air 门控控制新增节点速度。随后在节点内选最少评的 role，再选该 role 最少评的 task，以免无限可生成任务淹没其它任务（pp.3–4、18）。

节点 utility 对 task 和 role 分别均匀平均。best-belief 是 `Beta(1+S,1+F)` 工作后验的 5% 分位数，用保守估计选候选（p.4）。这不是由本文无条件建立的有限样本、选择后校准的真实成功率下界；理论条件见后文。

核心过程（p.4；算法 1 p.19；图 8 p.20）：

1. 在一个 epoch 内冻结评价器、候选节点和评分协议。
2. 同时搜索更好的任务程序和候选评价器。
3. checkpoint 比较当前评价器与 challengers，平局保留 incumbent。
4. 替换后清除所有**受旧 evaluator 影响的 utility records**，重算节点/子树/调度统计。
5. 原始工件与审计日志可以保留；以后若重新用它们计分，必须产生新准则下的新记录。未依赖这个 evaluator 的外部 anchor 记录保留。

依赖不仅是“谁最后打分”，也包括生成、抽样、replay 等路径（p.4、p.36）。这对科学验证器的启发比简单保存历史更具体：**历史材料可保存，历史材料在当前规范下是否仍算证据必须重新判定**。准则版本改变不能仅把旧分数重新缩放。

几何间隔 checkpoint 避免每一步重评整个档案；其 O(B) 结论是**记录重处理数量**的界，条件为每个 checkpoint 至多处理此前每条记录一次，不是整个科学验证计算成本无条件线性。

### 一个应保留的文内表述差异

图 9（p.21）称只有 evaluator-independent anchor 进入替换 gate，并把 adversarial samples 标为非 replacement gate；但算法 1（p.19）、正文 p.5、F.2.1（p.35）和 F.6.3（p.38）明确允许 **anchor + pool** 的加权分数参与替换。应以后者的具体算法/公式描述带 pool 的实验，不可把简图读成“每次都保证纯人类真值准确率提升”。本文已经报告了这种 trade-off：对抗 reviewer 的 APReS 准确率低于 HGM-H（p.26）。本轮未运行代码解决实现层面的歧义。

## 3. 评价数据、实验协议与资源（正文 pp.4–5；附录 C pp.20–25）

外部信号并未消失：

| 场景 | 任务 agent 的反馈 | evaluator 的固定 anchor | 测试规模/重要条件 |
|---|---|---|---|
| Polyglot coding | 可执行测试 + evolved reviewer | CRAVE 人类 accepted/rejected PR 标签 | coder 10 train /49 val /166 test；reviewer每split100条、50/50平衡（p.21） |
| DeepSWE coding | 官方执行测试 + evolved reviewer | 公开真实模型试跑中 pass/fail patch | 按 repository 隔离28 train /57 val /28 test；reviewer56/114/56平衡行（pp.22–23） |
| 科学论文 writing/review | 冻结当期 reviewer 的 Accept/Reject | APReS 已有论文 accept/reject | 每split100论文、50/50；writer用同split论文题名和摘要（p.23）；并非自行完成科学实验真实性核验 |
| IMO proof writing/grading | 冻结grader，满分7/7才作为接受 | IMO-GradingBench **人工评分** | grader100/100/100；prover20个held-out问题、3个模型grader（pp.23–24） |
| reward design | 固定host训练PPO后按外部fitness计分 | 固定模拟器/fitness | 每组5次搜索；每个最终reward designer生成6次jumping奖励，合计30次试验（p.24） |

DeepSWE 的 split 用三个参考模型各推理强度的历史失败率平衡难度和语言比例，保证 repository 不跨 split（p.23）。它不是 benchmark 官方预先给定切分；结论应绑定这28个测试任务。最接近正确的负 patch 平均91%测试通过，提高 reviewer 锚点难度。候选 coder/reviewer 看不到官方 verifier tests 和 reference solution。

**生成候选与选候选分开**：meta-agent 可以看 train 的结果、祖先 transcript 和 diff；看不到 validation outcomes。validation 驱动节点选择和 evaluator 替换，test只在事后评估使用（pp.5、18、25）。这比直接用同一批自生成得分当自改进证据更可靠，但有限重复 validation 的适应性选择仍不等于对所有新分布有保证。

模型与预算：Polyglot、paper、proof 主要用 GPT-5.5 low；DeepSWE 用 GPT-6 Astra high 的 meta-agent + low 的任务agent，两臂相同；机器人用 Nemotron 3 Ultra；mechanism ablation另用Nemotron模型（pp.5、21–24）。headline核心是每域一条RQGM和一条HGM-H搜索，总计8条，机器人另做每组5次；不能把三方模型panel当成独立搜索重复。

主报告比较 blended tokens（output 5×input），包括生成、train反馈和validation（p.5）；选择成本记为首次达到最高best-belief的时刻，并非全程总账。DeepSWE赢家成本587.2M vs428.6M，而全程2,876.8M vs2,532.7M（p.28，表14）。所以82.1% vs75.0%的最优点不能写成两个赢家恰好同token预算。作者另观察matched-token阶段相近、较长搜索中RQGM继续取得增益。

表4–6（p.22）列固定与可编辑面：固定置信分位、checkpoint与搜索预算等；meta-agent可改初始工具轮数/timeout/output tokens等，但受host外部预算限制。DeepSWE初始以mini-SWE-agent为工作框架；其它任务的初始task prompt很短（p.25），其演化结果不代表从零知识开始。

## 4. 主结果与不能忽略的反面（正文 pp.6–9；附录 D pp.26–29）

### 编码和机器人

| 结果 | 作者报告 | 合理解释与局限 |
|---|---|---|
| DeepSWE low effort | RQGM 82.1%，HGM-H 75.0%；held-out28任务（pp.6、23、26） | 约23/28 vs21/28，差2题；有限样本与单条搜索，不能宣布普遍显著或无限改进 |
| medium/high effort | RQGM均85.7%；HGM-H78.6/82.1（p.26） | 学到的harness可迁移推理强度；没有改变底座权重的直接证据 |
| Polyglot | 两类RQGM候选均71.7%，HGM-H69.9%；较低token成本达更高点（pp.6、26，图3） | 166题上的约1.8百分点差；可用于有限条件下辅助搜索增益 |
| walking→jumping | 0.365±0.053 vs0.306±0.128；5/5 vs3/5搜索找到jumping策略（p.6） | 外部设计的障碍课程，按固定PPO/fitness评估；不是evaluator自发制定全部目标 |

机器人 curriculum 在evaluation1/20/50引入逐渐加宽的障碍，同时保留向前走目标；held-out jumping从未出现在搜索任务池（p.24）。该实验支持按规则变化任务可改善迁移，不能当作无界或自主“研究品味”出现。

### 论文写作：提高的是评审接受率

表2（p.7）：HGM-H writer的四个模型reviewer平均接受率21.8%；RQGM generalist38.8%（约44.6M对42.5M tokens，作者称matched cost）；RQGM specialist40.5%，但用了221.8M。**1.78×与1.86×对应不同成本条件**，不能只报较大的倍数忽略预算。

判官差异非常大：Sakana只接受1%、2%、5%；HGM-H reviewer则接受64%、81%、86%。四名判官都是agent/prompt机制，headline调用使用同一GPT-5.5底座（p.21），不等于四个独立来源的科学真值。每writer100篇论文，Mean将400个paper×reviewer二元结果pool为Jeffreys区间（p.24）；同篇论文与共享模型的相关性不是这张表直接消除的。

论文由APReS题名/摘要条件化生成；没有新研究实验、事实来源或结论真实性的独立全链核验。p.10明示未把生成论文投给任何venue或展示给人类reviewer。p.39也明确panel只测cross-reviewer acceptance。**这组结果不能用于断言“科学质量提升了1.86倍”。**

### 证明：平均分与完全正确不可混写

表3（p.7）与表10（p.26）：RQGM specialist panel-mean4.33/7，高于static IMO25的4.07，P@6为61.7% vs55.0%；但是P@7是48.3%，**低于IMO25的55.0%**。它获得更多接近完整的证明，并非各指标全面胜出。

剔除与prover共演化的RQGM grader，另两grader给RQGM specialist均分4.03，IMO25为4.08，HGM-H为3.60。共演化grader单独给RQGM specialist4.95，说明选择哪个判官足以影响“超过人工设计强baseline”的表述。输出证明仍由模型评分，不是Lean等形式内核或人类专家逐证复核。20题×3grader的headline SEM，不代表60个独立数学问题；附录消融改用按问题cluster bootstrap，更应保留。

### 评价器本身的改进与代价

IMO grader在held-out100条人工评分上优于该论文静态baseline，约3×更少搜索成本（p.9图6）。这支持“有外部标注锚点时，可搜索出更好的grader”；不证明自评分闭环自行产出正确性定义。

APReS adversarial reviewer将AI与人类论文边际接受率拉近，但test accuracy从HGM-H88%降至80%（p.26表8）；相同总体接受率不自动证明条件校准、质量无偏或真实科学判定正确。对抗池把旧reviewer接受的生成文稿作为应拒绝对象，也没有人类逐项证明这些文稿必错。

尤其值得用于本课题的反例是p.31：在两个时期reviewer共同判过的337个DeepSWE补丁上，最终reviewer将**错误补丁接受率85%→19%**、balanced accuracy0.52→0.64；与此同时，**正确补丁接受率89%→47%**。看整段任期的表15还有不同总体比例，不能与共同337子集混用。更严格的检验器明显可能误伤正确工作流；只减少“漏检”不足以证明更有用。

### 替换、失效记录和消融

图4–5（pp.8–9）、图13（p.32）显示替换后档案重新排序，部分强谱系保留；no-erasure对照排名更固定。这是有限搜索轨迹的机制证据，不是永久进步证明。

附录表11–13（p.27）比较替换、对抗池、selective erasure及coupled HGM。固定reviewer最后把75份validation文稿全部接受，说明固定代理标准可能饱和；替换后人类anchor表现更好。各运行自己的writer acceptance**不可横向比较**，作者表注已强调。

proof ablation中完整机制的grader agreement67.3%，coupled HGM65.7%，95%问题bootstrap区间分别[57.6,76.9]和[55.9,75.1]；prover3.60[2.55,4.67]对3.05[2.11,4.04]。点估计支持完整机制，但宽重叠区间与不同模型消融不支持无条件“大幅稳定提升”。不从区间重叠本身推导正式显著性结论。

成本分解图10（p.28）表明大部分计算花在validation，不在代码修改；图11（p.29）显示大量已接受patch改共享基础设施。图12的13×是把更便宜任务模型换入后按价格折算的搜索成本，不能当成算法独立于模型价格节省13×算力。

## 5. 演化出的具体检查规则：与当前想法最直接的重合（附录 E pp.29–34）

这里比“co-evolution”大词更值得读；作者把谱系diff和meta-agent总结具体列出。

1. **不受流畅文风影响、主张要有证据**（pp.29–30）：论文reviewer由单句accept/reject变成conjunctive标准：贡献、技术、先前工作定位、证据支撑均需成立；另一分支则提醒对有实质证据但表述不完美的论文不要过严。两种规则都早期出现，对抗压力影响最后选择。
2. **区分未证引理与可合法简写**（p.30）：IMO grader先提取guideline关键步骤，再判学生文字是否真正证明，忽略似是而非的参考复述；后来又学习不要惩罚不同于参考解或简洁引用标准结果的正确证明。禁止无依据推导需要有“标准结果合法调用”的明确接口，否则会误拒。
3. **不因上下文缺失而编造错误**（p.30）：Polyglot reviewer明确写出 `Do not invent blockers from missing project context; the diff alone must show the defect.` 它还区分具体正确性风险与风格不满。这几乎直接对应“验证器不能自行加前提”。因此这条直觉本身已有近邻，不能仅换成科学场景便宣称新机制。
4. **修正可能破坏好证明**（p.31，Listing1；p.33表18）：获胜prover把继承的revision默认关闭，并改指令为保留基本可靠的初稿，不得把细致证明换成依赖未证冷僻定理的短答案。该例支持“纠错器自身会引入新错误”，同时提醒不能只奖励修改次数。
5. **调查假设与最终判决分离**（p.34，表19及审计prompt）：初次扩展把review分为repo研究和最终判决；每次拒绝需要具体execution/API call、required result、actual result、责任code path。后续扩展明确停止把investigator未经核验的hypotheses给最终judge。还写明`Missing extracts are not missing implementation`，必须把完整diff作用在base版本上看。
6. **原始证据和新增测试有权限边界**（pp.31、34）：更强reviewer读取repo/在scratch副本应用patch；coder可加regression tests，却保留既有tests/callers不变。重要的是可读事实、可提假设、可改代码、不可改评价框架分开。

这些约束大部分是**演化出来的prompt/代码行为**，不是逐推理步形式验证或机器可重放证书。p.34的audit仍使用“mentally apply”diff的指令；写出了具体失败调用不自动等于真实执行已复现。对科学验证器真正有价值的下一步是检查这种约束何时能被结构化机制强制，以及相较提示规则的额外收益；这仍需排查其它形式/证据验证文献，不能在本次阅读后直接下新颖性结论。

## 6. 理论到底保证了什么（附录 F pp.34–38）

完整读了假设、定义、命题与证明，并对pp.35–38公式渲染复核。理论不等于“系统永远变聪明”。

| 结果 | 条件与内容 | 不能推出 |
|---|---|---|
| 引用的HGM Theorem1（pp.34–35） | 固定criterion、外部预算、binary stationary outcomes；理想CMP oracle/proof object在empirical budget外 | 本系统已实现可计算的通用最优自改进oracle |
| Prop1（p.35） | 每cell采样比例收敛且经验率收敛，pool后Beta均值收敛到role-task加权utility | 小样本适应性筛选后的分数天然可靠 |
| Prop2–3（pp.36–37） | 依赖记录带criterion版本；替换删除失效记录；每epoch工作空间/生成与评分法则固定 | 自动保证科学前提真实、规范解释忠实、跨epoch分数直接可比 |
| Prop4（p.37） | working posterior内部的分位数定义；多次选择的union bound额外要求每次选择后的真实违规概率受控 | 直接给出无假设95%真实置信保证 |
| Prop5（p.37） | 在每次checkpoint的历史条件下，后续epoch是固定criterion问题 | utility改变后仍有同一全局目标的单调进步 |
| Prop6（pp.37–38） | 几何checkpoint，每次至多重处理此前每条记录，次数≤ρB/(ρ−1) | 真实工具/模型调用总成本必定线性 |
| Prop7（p.38） | 固定有限验证集、固定标签、候选确定二元正确表、exact comparison、保留incumbent且ties不换；anchor分数单调 | OOD能力或科学真实性单调；实际上有限等权N项时最多N次严格替换，最后停止 |
| Prop8（p.38） | 所有候选估分与同一Q的偏差≤η；被选新e的Q≥旧e的Q−2η | 有限预算随机best-belief严格不回退 |

带对抗池的实际目标（F.6.3，p.38）为

`Q_P(e) = p_+(e)/2 + p_-(e)/4 + r_P(e)/4`，

其中前两项为正/负anchor准确率，最后一项为当前生成池拒绝率。池跨epoch变化后，作者只给出 `Q_{j+1}(e_{j+1}) ≥ Q_j(e_j) − 2η_j − δ_j`，δ为目标漂移幅度。这是带误差和漂移的界，**不是纯anchor或所有科学目标都升高**。前两项标签不变不代表trade-off不存在。

特别值得迁移的是p.36对raw artifacts / audit logs与计分record的区分：前者可跨版本留存，后者须有当前criterion下的有效来源。这可以启发科学证据工作流记录“事实版本—使用前提—规则版本—结论”的依赖，但本文本身未提供自然科学语义的完全形式化。

## 7. 限制与相关工作（附录 G–H pp.39–40）

作者自行承认三条核心限制：provider模型更新和工具非确定性可破坏epoch stationarity；论文/证明只由自动panel评价；弱、噪声或有偏anchor会允许跨epoch漂移，即使好anchor也受自己的decision boundary限制（p.39）。这些是论文自己的限制，不是外加的泛化担忧。

扩展相关工作区分权重自训练、代码空间递归、共演化rubric、judge偏倚、动态benchmark与自动科研。其近邻还包括SCORE、EvoRubrics、Who Grades the Grader?等（pp.39–40；参考文献pp.11–14）；本轮未全文阅读它们，也未进一步拉大补读范围。

本文最后仍把APReS、IMO human grades、CRAVE作为外部锚点再次明写（p.40）。结论只能是**有固定外部依据和受控评价更新时，共演化可以在有限实验中改善某些搜索/评价结果**，不能写成“无外部信息的验证器已实现持续递归科学自证”。

## 8. 对受限科学验证器的判断与可推翻问题

这篇原始论文同时提供支持、重合和警示。

**支持**：任务agent与evaluator可共同改善，同时把不可改的评分/证据入口留在外部；记录版本和失效重评能避免不同评价尺度混用。一个科学验证器可以演化搜索错误的方法、组织证据的方式和合法规则组合，而不拥有自行宣布新科学前提为真的权限。

**重合**：不编造blocker、每次拒绝给具体反例、隔离未经核验的调查假设、避免修订引入未证引理，已经出现在RQGM的实际获胜谱系（pp.30–34）。因此“给生成器再配一个会反思的检验器”或“检验器不加假设”不足以构成清晰原创点。

**警示**：提高拒绝倾向可降低错放同时拒绝大量正确工件；模型panel得分不等于真实科学质量；正式保证只维护当期评价一致性，不创造真值。固定有限anchor也不允许用单调分数无限证明进步。

一个更可检验的设想是：在相同底座、数据和预算下，对比普通rubric reviewer、RQGM式可演化reviewer，以及**每项拒绝必须附可重放/可形式检查的反例或前提缺口证据**的受限reviewer。允许新检查程序，但准入必须通过不可改的检查内核；新增实验事实走明确外部证据更新流程。至少分别衡量：错误接受、正确拒绝、无依据新前提、输出证据可重放性、条件域迁移、每轮收益和总成本。

能否定该设想的结果包括：约束只导致泛化拒绝/弃答、检查证书仍偷渡同样的未验证假设、相对预算匹配的更多执行测试没有收益、或在条件域改变后失效。这个proposal是本次阅读的推论，本文没有检验该科学工作流方案。
