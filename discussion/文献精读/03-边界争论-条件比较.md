# RLVR 边界争论：两篇后续全文的条件比较

2026-10-14。本分支完整阅读 ProRL（2505.24864v1，26 页）和 New Skills or Sharper Primitives?（2602.08281v1，15 页）；正文、附录、参考文献与全部实证图已核查。清华论文最新 v5 的全文由主代理负责，本分支对其 §4.5 / C.8 进行了检索定位，并按主代理核查结果对齐。所有模型表现为论文报告，本轮未复现。

## 可以同时成立的结论

清华对部分公开 RLVR 模型发现“小 k 提升、大 k 覆盖下降”，与后续研究在特定任务上发现“新组合或新题的有限预算可解性提升”**可以共存**。区别涉及起点、任务分布、训练方式、成功事件和可用预算；同时两类论文都不能仅凭有限采样推断数学意义上的输出 support 是否增加。

| 比较条件 | 清华最新 v5 | ProRL | New Skills or Sharper Primitives? |
|---|---|---|---|
| 主要问题 | 当前若干 RLVR recipe 是否扩大推理覆盖 | 长时间、稳定、多领域 RL 是否在部分任务扩大覆盖 | 原子技能强化能否让未训练的组合任务变得可解 |
| 起点 | 多系列公开模型；具体应按任务区分 pretrained 与 instruction-tuned | DeepSeek-R1-Distill-Qwen-1.5B，已有强模型蒸馏 | Qwen、Llama、Gemma 六个起始 checkpoint，多数 instruction-tuned |
| 训练变化 | 对既有 pure-RLVR 模型的比较及自训 | DAPO 组件、KL、reference/optimizer resets；训练阶段中加数据、改 reward、改 rollout 和上下文 | 仅训练 1-operation 合成题，100 步 GRPO；测试 2—5-operation 组合 |
| 外部约束 | 标准任务正确答案/检验器 | 136K 外部任务，测试用例、规则、科学题源答案和数据筛选 | 12800 合成题及人定代数规则/确定性答案 |
| 测量 | 大 k 及覆盖、PPL；v5 已有匹配输出熵实验 | 固定 T=.6/top-p=.95，256 采样；无 matched-entropy 复验 | 每题 128 采样，逐题阈值；评估温度未充分报告 |
| 已读后续中的正证据 | 不由本分支重报数值 | Codecontests/TACO、OOD boxnet 与图规模泛化提高 | 六模型组合题 pass@128 提高；部分 base 0/128 条目达到 RL 成功率≥.125 |
| 同时观察的负证据 | 部分训练模型在大 k 退化 | 同一论文的 Minerva、LiveCodeBench 大 k 退化 | 原子题能力侵蚀，Llama/Gemma 尤明显 |
| 不足以断言 | 一切 RLVR 都不可能扩展任何能力 | 无外部信息的无限自我改进；训练时间是唯一因果因素 | 凭空获得新知识/新原子算子；独立乘积是一般推理定理 |

注意最新版本：不能沿用“清华没测温度/熵”的旧式反驳。清华 v5 §4.5 与 Fig18 对 Qwen2.5-7B / SimpleRLZoo 增大 RL 采样温度以近似匹配 base T=.6 的输出熵，作者报告覆盖仍较低。该实验限定了“只因 token entropy 下降”的解释；它也不等于所有模型/任务/语义策略多样性均已控制。

## 把“新能力”拆成可检验层次

1. **概率和效率改善**：已有候选更容易被采到；pass@1 提升。两边都接受这会发生。
2. **给定预算的覆盖改善**：某些题在固定 K 次内更可能出现有效解。ProRL 与 New Skills 提供正证据；清华的一些条件提供反向证据。
3. **新的技能组合**：原子技能本身不新，可靠组合可以新到达操作门槛。New Skills 的 atomic/composite split 支持这种解释；它不要求基本事实或原子规则由模型创造。
4. **新的基础策略或知识**：需要更强的策略表示、任务控制与外部信息追踪；仅靠大 k、文本“新颖性”或 base 零成功不足以确立。
5. **递归改进自身改进机制**：两篇主要改变模型权重，不直接测试自我改写训练算法、检验器或长期无界 RSI。不能把它们的多轮参数更新直接等同于严格 RSI。

有限采样是两派共同的测量边界。固定 q 时，独立抽样有 `P(至少一次成功)=1-(1-p)^K`。0/128 的单侧 95% 上界约为 p≤.0231，0/256 约为 p≤.0116；都不能推出 p=0。New Skills 使用的 p=.3^5≈.00243，在128次中仍有约26.8%机会成功，在1024次中约91.7%。因此“从未观察到”与“不在模型能力中”不是同一个断言。

另一个共同边界是 **success 由 verifier 定义**。ProRL 明确指出基础模型的 `<answer>` 格式适配问题；New Skills 主要验 boxed 最终结果。对需要检查推导过程的科学工作流，最终值或部分测试通过不能代替“每一步允许、每个前提有出处”。

## 对当前科学验证器的启发：证据支持到哪里

当前约束是“不能自行增加未经验证的科学前提，推导要可检查”。这与学习新组合并不冲突：系统可以在固定前提与规则下改进搜索顺序、策略组合或错误定位，成功候选仍由独立检查器接纳。**扩大可检查推导的覆盖**和**增加可用科学前提**应作为两个不同操作管理。

外部 verifier 本身带有信息。即便只返回一位对/错，重复查询也在告诉模型哪些输出符合人为给定规则；无需提供整条解答也能产生学习。因此不能把“没有教师 CoT”表述为“没有外部知识来源”，也不能因奖励可计算就默认它与科学真值等价。

由全文可推出的研究问题，而非已经成立的创新点：

- 在锁定前提与规则、锁定 verifier 版本的条件下，仅改进原子检查策略，能否提高未见组合错误的识别与修复？New Skills 给出受控代数先例，尚未验证开放科学。
- 在总推理 token/工具调用预算匹配时，改进增加了多少严格通过的题目，损失了多少原本会的题目？需要逐题 gain/loss，而非只看平均分。
- 当消除格式失败、调试 verifier 阈值并扩大采样后，所谓“新覆盖”还剩多少？ProRL 的格式问题使这一对照有明确必要性。
- 若奖励只看终局正确，是否会偏向跳步、偷偷增加前提或碰巧抵消错误？应让整条推导有效性成为单独评价，而不是用 pass@k 代理它。

这些方向已有 atomic/compositional RL 和验证任务的直接近邻，尚不足以宣称原创。更适合作为后续选题的可证伪门槛。
