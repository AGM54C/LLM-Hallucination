整理 AI 幻觉相关的文献、讨论、数据和候选 IDEA。**目前处于选题阶段，尚未确定具体研究方案；研究范围不限定于 AI 科研。**

选题优先要求：错误有明确含义，判断有可核验依据，改进能通过独立评价与强基线比较。既看是否减少幻觉，也看是否误改正确内容或引入新错误。

**科研 IDEA 生成保留为自用探索，不作为本项目的论文方向。** 当前范围与筛选标准见[选题范围与评价标准](discussion/选题范围与评价标准.md)。

## 已有实验处于什么位置

化学表格决策只是一个前期候选。V1 未证明选样训练优势；V5 中去掉原表后，两个模型的准确率分别下降 **0.76、2.50 个百分点**，不支持预期的修复效果。

**该候选的现有版本已停止推进，作为负结果归档。** 它没有验证科学机理约束、实验可实施性修复或新的模型内部机制，不作为本仓库的既定方向。详见[候选取舍](候选IDEA集合/04-化学表格决策-已归档.md)和[V5 结果](experiments/results/v5/结果分析.md)。
