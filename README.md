# 科学机理约束的隐性风险判定与修复

按[课题要求](https://notes.sjtu.edu.cn/f8gmS3wVQ4i4slalHJ-6Yw)整理的文献、讨论、数据和候选 IDEA。**目前处于选题阶段，尚未确定具体研究方案。**

核心问题是：科研内容看似合理时，如何检查它的证据、成立条件和实验步骤，找到隐性错误，并核验修复是否有效？

| 课题要求 | 需要回答的问题 |
|---|---|
| 科学推理链的结构化表示与约束建模 | 每个断言依据什么证据、依赖什么条件？事实、因果、边界、资源约束怎样表达和检查？ |
| 科学机理约束的因果一致性判定 | 因果方向、条件依赖与适用范围是否成立？反事实检查能排除哪些错误？ |
| 实验方案可实施性判定与修复 | 步骤、材料、参数、对照和资源是否齐备？修复后能否执行，是否引入新问题？ |

第二项见原文总图；网页正文详细展开第一、第三项。科学机理约束指领域规律和成立条件，不能用模型内部电路分析代替。文献的具体对应关系与缺口见[逐项对照](related%20work/README.md#与课题逐项对应)。

## 已有实验处于什么位置

化学表格决策只是一个前期候选。V1 未证明选样训练优势；V5 中去掉原表后，两个模型的准确率分别下降 **0.76、2.50 个百分点**，不支持预期的修复效果。

**该候选的现有版本已停止推进，作为负结果归档。** 它没有验证科学机理约束、实验可实施性修复或新的模型内部机制，不作为本仓库的既定方向。详见[候选取舍](候选IDEA集合/04-化学表格决策-已归档.md)和[V5 结果](experiments/results/v5/结果分析.md)。
