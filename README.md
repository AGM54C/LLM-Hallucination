# 科学证据与决策

研究一个具体问题：**模型面对同一份科学证据，为什么会因顺序、标签或提问方式变化而作出错误决策？**

目前用真实化学反应表做受控实验：给定底物和实验条件，从四个配体中选择记录产率最高或最低的一项。这是证据检索与数值决策任务，尚不涉及发现新的化学机理。

## 当前进展 · 2026-10-09

- **已有现象：**同一数据换序后，直接决策表现会下降；显式读值可以修复很多错误，但仍存在数值正确、选择错误的情况。
- **训练结论：**当前高分歧选样没有胜过普通 SFT，暂不支持它具有独立训练优势。
- **V5 已完成并通过复核：**去掉表格、只保留四个数，并没有稳定改善决策。不能据此宣称验证了内部机制。

| V5 工作流准确率 | 原始 Qwen3-14B | 普通 SFT |
|---|---:|---:|
| 仅四个数，再问选择 | 92.54% | 92.61% |
| 原表＋同样四个数，再问选择 | 93.30% | 95.11% |
| 同样读数交给程序比较 | 97.73% | 98.45% |

每格分母为 2,640，包含 4 次上游读值失败。同一批任务有重复呈现，两模型也有关联，不能当成独立重复实验。详情见 [V5 结果](experiments/results/v5/结果分析.md)。

## 不用 GPU 也能复核

Python 3.11+，在仓库根目录运行：

```bash
python experiments/tools/replay_results.py
```

程序从压缩原始记录重建 V4、V5 的提示、评分和汇总，核对数据与源码哈希；不联网、不加载模型。运行新实验见[代码说明](experiments/scientific-evidence-learning/README.md)。
